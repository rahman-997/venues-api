# BookHaven free deployment snapshot

This directory contains the BookHaven deployment archive split into Base64 chunks so the existing repository main branch remains untouched.

Render restores it with:

```sh
cat bookhaven-deploy/archive.part* | base64 -d | tar -xzf -
```

Deployment source archive SHA-256:

`4c0c05c5958d491b00560373b21314f24e201495f0a5eb6271b7d1388dd9aa3a`

The root `render.yaml` deliberately uses explicit `npm install --no-audit --no-fund` commands because this snapshot does not contain package-lock files. Runtime is pinned to Node 24 through `.node-version`.

Required Render secrets: `MONGO_URI`, `ADMIN_EMAIL`, and `ADMIN_PASSWORD`. `JWT_SECRET` is generated by the Blueprint.
